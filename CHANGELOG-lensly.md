# Lensly Changelog

All notable changes to Lensly. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). See [CONTRIBUTING.md](CONTRIBUTING.md) for how to add an entry, and for the choices we made where that specification is silent.

## [Unreleased]

## [1.3.0] - 2026-11-28

**Upgrading:** Vaults from earlier versions of Lensly are erased on the first unlock after updating, because the vault format changed for security. Keep your recovery phrases (and passphrases, if you set any) so you can restore your wallets.

### Added

- Address Book entries take a group, which the owner sets on the add and edit form. A pairing now carries groups in format 8, so Lumio shows them after the wallet is paired again, and entries saved by earlier versions of Lensly keep working. [Issue #846](https://github.com/al-shukran/airvault/issues/846)
- Wallets hold only the chain apps the user installs. A new Mnemonic wallet starts with Bitcoin only, and each Mnemonic wallet has an Apps screen with Install and Uninstall. Uninstalling an app removes its accounts, and their names, labels and groups for that chain are lost. [Issue #941](https://github.com/al-shukran/airvault/issues/941)

### Changed

- A name in the review summary is now followed by the start and the end of its address, so a saved name never stands for an address you have not checked. [Issue #1249](https://github.com/al-shukran/airvault/issues/1249)
- A name that spells an address in groups, or with dashes, dots or look-alike letters, is now refused when saved and shown as the address.
- A review now shows "First time. Check every group." for an address that is not saved, shows "Saved for all EVM networks" under a saved EVM address, and warns in amber when an unsaved address shares its first and last 4 characters with a saved entry. Names are shown as plain text. [Issue #1089](https://github.com/al-shukran/airvault/issues/1089)
- A signed catalog package can now correct a built-in network or token, revoke a signing key that has leaked, and carry the Solana fee constants behind the Max Fee, so these no longer wait for a Lensly update. [Issue #1529](https://github.com/al-shukran/airvault/issues/1529)
- A signed denylist entry can now name an address that appears inside a request, such as the spender of an approval or permit, the operator of an NFT grant, or the recipient of a transfer, so a known drainer is caught where it is asked for. [Issue #1508](https://github.com/al-shukran/airvault/issues/1508)
- Every Address Book row now names the chain of its address (Ethereum, Bitcoin, Solana or Algorand) under the entry name, before the label. [Issue #1104](https://github.com/al-shukran/airvault/issues/1104)
- Names in the signing review stay readable beside the address for Arabic and Hebrew, a name that looks like an address is refused when saved and shown as the address, and an address that looks like one of your own accounts is flagged. [Issue #1182](https://github.com/al-shukran/airvault/issues/1182) [Issue #1187](https://github.com/al-shukran/airvault/issues/1187)
- Screens now slide in from the right over a still screen and slide out to the right on back, with no fade or dip, and the back gesture follows the finger. [Issue #1158](https://github.com/al-shukran/airvault/issues/1158)
- The Licences screen now names Lifecycle 2.11.0, the current SLF4J copyright and Bouncy Castle bcutil, which ship in the app. [Issue #1135](https://github.com/al-shukran/airvault/issues/1135)
- The approved contracts list in Settings now writes each contract address as its first and last two groups of four, such as 0x7f39 c581 … 935e 2ca0, the same way the review screens write it, instead of the first six and last four characters. [Issue #1684](https://github.com/al-shukran/airvault/issues/1684)
- The back swipe now slides the page to the right with your finger and reveals the previous page beneath, instead of shrinking it into a rounded card.
- The camera cover and the unlock, password and unavailable screens now set their large headings in Archivo instead of the dot-matrix face.
- Uninstalling the Bitcoin or Ethereum app from a wallet now keeps the names, labels and groups of its accounts, and installing it again brings them back. [Issue #1111](https://github.com/al-shukran/airvault/issues/1111)
- Unlocking with the Duress Password now erases the real vault, and the decoy becomes the vault. The Duress Password screen says so, and the recovery phrase, plus your passphrase if you set one, restores the wallets. [Issue #1620](https://github.com/al-shukran/airvault/issues/1620)
