# Token icons (SVG)

67 full-colour SVG logos for the most-traded ERC-20 tokens.

- **Source:** [0xa3k5/web3icons](https://github.com/0xa3k5/web3icons), `raw-svgs/tokens/branded` (64 files), plus `busd`, `aero`, `bal` from [token-icons](https://iconify.design) via the Iconify API. Both are MIT; logos and trademarks remain property of their owners.
- **Naming:** lowercase token symbol, one file per token: `<symbol>.svg`. Lowercase avoids case-sensitive filesystem surprises when resolving by symbol.
