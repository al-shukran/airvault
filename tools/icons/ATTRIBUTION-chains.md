# Chain icons (SVG)

61 full-colour SVG logos for Bitcoin, Ethereum and popular EVM chains.

- **Source:** [0xa3k5/web3icons](https://github.com/0xa3k5/web3icons), `raw-svgs/networks/branded` (MIT licence; logos and trademarks remain property of their owners).
- **Naming:** kebab-case slug of the chain name, matching the source file name. One file per chain: `<slug>.svg`.
- **Style:** `branded` = the chain's normal colour logo. The source repo also ships `mono` and `background` variants if a wallet UI needs round avatars or single-colour marks.

No logo in the source set: opBNB, Hyperliquid L1, Story, Monad, Somnia, Eclipse, and most other pre-launch or niche L1s. If you need one, drop the official SVG here using the same kebab-case naming.
