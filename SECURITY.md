# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Report them privately with GitHub's private vulnerability reporting: open the repository's **Security** tab, choose **Report a vulnerability**, and fill in the form. Only you and the repository's maintainers can see the report.

A useful report includes:

- the affected app (Lensly or Lumio) and its version or commit;
- the steps needed to reproduce the problem, or a proof of concept;
- what an attacker could do and what data or keys would be exposed;
- any suggested fix, if you have one.

## Supported Versions

Fixes are made on the `master` branch and shipped in the next release of the affected app. Earlier releases do not receive separate patches.
