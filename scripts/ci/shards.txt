# A pure JVM module runs whole, so its line names the class `*`. Lanes: shard-1..shard-6 run the unit tests (--offline);
# verify-app and verify-lumio run the Roborazzi pixel tests of one module each, with verifyRoborazziDebug; fuzz replays the Jazzer
# seeds with -PfuzzLane.

# fuzz), so a new test needs no line here. scripts/ci/check-partitions.sh fails when a class is listed twice or no longer exists. The balance comes
# from measured durations (JUnit XML of the shard runs), see scripts/ci/README.md.
