# Test lanes for scripts/ci/run-partition.sh: one line per test class, "<lane> <gradle module> <fully qualified class>".
# A pure JVM module runs whole, so its line names the class `*`. Lanes: shard-1..shard-10 run the unit tests (--offline);
# verify-app and verify-lumio run the Roborazzi pixel tests of one module each, with verifyRoborazziDebug; fuzz replays the Jazzer
# seeds with -PfuzzLane.
# A unit with no line goes to shard-6, the catch-all lane, unless it is a screenshot test of :app or :lumio (verify-app or
# verify-lumio by name) or a fuzz target (fuzz). scripts/ci/check-partitions.sh fails when a class is listed twice, no longer
# exists, or would fall into shard-6 unlisted. The balance comes from measured durations (JUnit XML of the shard runs), see
# scripts/ci/README.md.
