# Test lanes for scripts/ci/run-partition.sh: one line per test class, "<lane> <gradle module> <fully qualified class>".
# A pure JVM module runs whole, so its line names the class `*`. Lanes: shard-1..shard-8 run the unit tests (--offline);
# verify runs the Roborazzi pixel tests with verifyRoborazziDebug; fuzz replays the Jazzer seeds with -PfuzzLane.
# A test class with no line is not an error: it runs in its default lane (shard-2..8 by a hash of its name, or verify or fuzz by name), so a new test
# needs no line here. scripts/ci/check-partitions.sh fails when a class is listed twice or no longer exists. The balance comes
# from measured durations: scripts/ci/balance-shards.py rewrites the shard lines, see scripts/ci/README.md.
