Lumio now protects its App Password against offline guessing from a copy of the vault files, closes a way to put an older vault key file back after a password change, and erases a vault it cannot verify instead of leaving it stuck. Vaults made by earlier versions are erased on their first unlock after this update, so set Lumio up again.
