The Solana review now counts the compute budget instruction in its default fee, shows a nonce account's funds as a deposit that its authority can withdraw, reads token approvals, authority changes, burns, closes and nonce withdrawals instead of showing raw bytes, and no longer marks a request as a testnet from a cluster that the sender merely claims. It refuses a transaction with a compute budget instruction it cannot read exactly, since the fee shown could be too low, warns when a new account goes to a program other than System or a token program or a closed token account sends its SOL to another address, and no longer calls a transaction with an unread instruction a send.
