Lensly now makes every record file in the vault folder one of a few fixed sizes, whether it holds a value or not, so the file sizes no longer show which records hold a value or that a Decoy Vault was used. Vaults made by earlier versions are erased on their first unlock after this update, so keep a recovery phrase for every wallet and restore your wallets from it.
