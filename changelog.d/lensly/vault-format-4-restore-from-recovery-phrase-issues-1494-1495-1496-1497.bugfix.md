Lensly now protects the App Password and Duress Password against offline guessing from a copy of the vault files, closes a way to put an older vault key file back after a password change, hides that a Decoy Vault exists in the records folder, and erases a vault it cannot verify instead of leaving it stuck. Vaults made by earlier versions are erased on their first unlock after this update, so keep the recovery phrase and, if you set one, the passphrase for every wallet, then restore your wallets from both.
